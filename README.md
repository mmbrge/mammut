# سیستم جامع مالی بیمه ماموت

اپلیکیشن دسکتاپ (Windows, Python + customtkinter) برای مدیریت مالی بیمه‌نامه‌ها، تقسیم و پیگیری اقساط، تسویه پرداخت‌ها، و تولید گزارش‌های اکسل/Word.

## پیش‌نیازها

- Python 3.10+
- ویندوز (به دلیل استفاده از `os.startfile` و مسیر پیش‌فرض داده‌ها روی `C:\...` — یکی از موارد بازسازی آینده، رفع محدودیت چندسکویی است)

## نصب

```bash
pip install -r requirements.txt
python main.py
```

فونت «Vazir» باید روی سیستم نصب باشد تا رابط کاربری به‌درستی نمایش داده شود.

## وضعیت فعلی این نسخه

این نسخه، نقطه‌ی شروع (baseline) پروژه در ریپازیتوری است. یک بررسی کامل کد انجام شد و **اولین دسته از اصلاحات حیاتی (امنیت/پایداری)** روی آن اعمال شده:

- حذف رمز عبور هاردکد؛ رمز مدیریت اکنون در اولین اجرا تعیین و به‌صورت هش‌شده (PBKDF2-HMAC-SHA256) در `config.json` ذخیره می‌شود و از «تنظیمات سیستم» قابل تغییر است.
- پارامتری‌کردن کامل کوئری‌های SQL که پیش‌تر با f-string ساخته می‌شدند.
- گرفتن نسخه پشتیبان خودکار (zip از دیتابیس + بایگانی) پیش از «حذف کلی اطلاعات»، به‌همراه الزام تایید رمز مدیریت برای این عملیات.
- افزودن سیستم `logging` (فایل لاگ در پوشه `Logs` کنار داده‌های برنامه) و جایگزینی مهم‌ترین `except: pass`های بی‌صدا با ثبت خطا.

## کارهای پیشنهادی بعدی (برای دورهای بعدی توسعه)

**ریفکتور معماری**
- تفکیک فایل تک‌پارچه به ماژول‌های `db.py` / `services/` / `reports/` / `ui/` / `config.py`.
- خروج مقادیر هاردکد (تعداد اقساط = ۹، رنگ‌ها، مسیر پایه) به ثابت‌های قابل‌تنظیم.
- تولید گزارش اکسل روی ترد جدا یا با نشانگر پیشرفت، تا در دیتاست‌های بزرگ UI فریز نشود.

**قابلیت‌های تکمیلی**
- کاربران واقعی با نقش (ادمین/کاربر عادی).
- ویرایش/حذف بیمه‌نامه و قسط پس از ثبت.
- تاریخچه تغییرات (Audit trail) برای هر تسویه.
- پشتیبانی چندسکویی (حذف `os.startfile`، انتخاب پوشه‌ی داده در اولین اجرا به‌جای مسیر هاردکد ویندوزی).
- تست‌های خودکار برای توابع خالص (`clean_number`, `get_period`, `get_due_date`, `resolve_column`).
- گزارش‌های تحلیلی بیشتر در داشبورد (نمودار وصولی ماهانه، مانده مطالبات).
